Developer infrastructure · Jun – Oct 2026

Coding-agent operations & gateway

Infrastructure for supervising long-running coding agents without losing instructions, approvals or session context.

Engineering tooling

My role

Designed and built the agent coordination workflows and the EC2-hosted gateway.

The problem

An agent accepting a message is not the same as an agent executing it. Long-running work needs durable state, recoverability and clear human control.

What I built

  • Persistent and resumable agent sessions with per-agent queues.
  • Urgent interrupts, agent-to-agent messaging, decision ledgers and watchdogs.
  • Approval boundaries for consequential operations and evidence-based review gates.
  • Task routing, role-based workflows, budget controls and blocked-work escalation.

Decisions that mattered

  • Kept queued instructions until a session could actually accept them.
  • Separated autonomous implementation from approval of production writes and merges.
  • Required evidence of completed behavior instead of relying on an agent’s done message.

Where it landed

Supported longer-running, multi-agent engineering workflows while retaining human control over consequential actions.

Toolkit

  • TypeScript
  • Node.js / Bun
  • EC2
  • Discord / chat integrations
  • Agent RPC
